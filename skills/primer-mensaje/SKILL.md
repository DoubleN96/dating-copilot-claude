# Primer mensaje

1. Lee su perfil completo (`tinder.py perfil ID` / `hinge.py perfil NOMBRE` / `bumble.py perfil NOMBRE`).
2. Busca **algo poco habitual** de su perfil (mejor un prompt que una foto) para comentar o picar un poco. Si no hay nada, usa una plantilla de repertorio de `tecnicas_videos.md` §2 por tipo de chica (y adáptala).
3. Reglas: corto (1-2 líneas), ligero, algo irónico, de hombre a mujer, sin "hola qué tal", sin halagos físicos, el dueño en marco positivo. Español salvo que ella escriba en otro idioma.
   - Tinder (§2.2): abre él. Hinge (§2.3): comenta un prompt suyo o responde al like que ella dio a un prompt de él. Bumble (§2.4): un solo mensaje para abrir, que cuente.
4. Envía con el script de la app (ver skill `revisar-y-responder` paso 4). Un primer mensaje por match; si no contesta, no insistas más de una vez (y solo pasados 2-3 días).
